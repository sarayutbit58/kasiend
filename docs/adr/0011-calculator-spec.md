# Spec เครื่องคำนวณเงินสำรองฉุกเฉิน (ตัวแรก)

Input: (1) ค่าใช้จ่ายจำเป็นต่อเดือน บาท (บังคับ — ใช้ค่าใช้จ่ายเป็นฐาน ไม่ใช้รายได้ เพราะฐานรายได้ทำให้เป้าเกินจริง) (2) ประเภทงาน: ประจำ / ฟรีแลนซ์ / ธุรกิจส่วนตัว (3) เงินออมปัจจุบัน บาท (4) ออมต่อเดือน บาท

ตัวคูณ (default ผู้ใช้ปรับได้ — เป็นสมมติฐาน ไม่ใช่มาตรฐานทางการ): ประจำ ×6 เดือน, ฟรีแลนซ์ ×9, ธุรกิจส่วนตัว ×12

Output: เป้าเงินสำรอง = ค่าใช้จ่าย/เดือน × ตัวคูณ; ถ้าออม/เดือน > 0 และยังไม่ถึงเป้า แสดง "อีก N เดือนจะถึงเป้า" โดย N = ceil((เป้า − เงินออมปัจจุบัน) / ออมต่อเดือน); ถ้าถึงเป้าแล้วแสดงข้อความแสดงความยินดี

คำนวณทั้งหมดใน browser (client-side) เท่านั้น ไม่ส่งข้อมูลออกนอกเครื่องผู้ใช้ disclaimer ต้องเด่นชัด ไม่ฝัง footer เงียบๆ: "เครื่องมือเพื่อการศึกษา ไม่ใช่คำแนะนำทางการเงินส่วนบุคคล"
