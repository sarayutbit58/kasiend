# ADR 0022: Thai Official Knowledge Base as Design Source

## Decision
รับชุด Markdown ที่ผู้สร้างแปลงจากคู่มือทางการ (สปสช., กรมบัญชีกลาง, ประกันสังคม, กบข., SET, ก.ล.ต., สวรส.) เก็บใน `knowledge/` เป็น **ฐานออกแบบ** ของ KasienD

## วิธีใช้
- ใช้จัดลำดับ Stage, สมมติฐาน, ข้อความภาษาคน, checklist สิทธิ/แหล่งเงินออม, และบทความ
- ห้าม copy เนื้อหาทั้งเล่มลง `index.html`
- ห้ามแนะนำผลิตภัณฑ์เฉพาะบุคคล
- ตัวเลขสิทธิ/อัตราต้องตรวจความทันสมัยก่อนเผยแพร่
- ลิงก์ภายนอกยังต้องผ่าน Curation Owner

## ทำไม
ทำให้แอพตรงบริบทคนไทย (3 กองทุนสุขภาพ, PVD/กบข./SSO, freelancer) โดยไม่กลายเป็น encyclopedia ที่ไม่มีคนใช้
