# Known tension: monetization เฟส 2 จะดึง PDPA กลับเข้ามา

ความตึงระหว่าง ADR 0002 (อยากเก็บค่าสมาชิกรายเดือน/โฆษณาภายหลัง) กับ ADR 0006 (เฟสแรกไม่เก็บข้อมูล ไม่มี login): วันที่เริ่มเก็บเงินรายเดือนได้ จำเป็นต้องมีระบบสมาชิก/login และฐานข้อมูลผู้ใช้ ซึ่งจะทำให้เข้าข่าย PDPA และต้องมีนโยบายความเป็นส่วนตัว/ระบบชำระเงิน บันทึกไว้เพื่อวางแผนเฟส 2 — ยังไม่สร้างตอนนี้
