# ADR 0024: Calculator Backlog from Thai Knowledge (no build yet)

## Decision
บันทึกเครื่องคำนวณ/โมดูลที่อาจสร้างจาก `knowledge/` เป็น **backlog หลังมีผู้ใช้จริง**  
รอบนี้ (Q37=ง) **ไม่เขียนโค้ด calculator ใหม่** และไม่เพิ่ม calc #4 ก่อนมีคนลอง v1.7

## Backlog (เรียงตามความเข้ากับ Stage Journey)

| ID | แนวคิด | แหล่ง knowledge | หมายเหตุกฎหมาย |
|---|---|---|---|
| B1 | ประมาณการบำนาญ/บำเหน็จชราภาพ ประกันสังคม (การศึกษา) | 04, 07, 13 | ใช้สูตรสาธารณะ + disclaimer; ไม่รับประกันสิทธิจริง |
| B2 | ช่องว่างเงิน 3 ก้อน (เป้าใช้ − แหล่งเงินที่มี = ต้องออมเพิ่ม) | 05, 11, 14 | ต่อยอด Stage 3 ได้โดยไม่ต้องเป็นหน้าแยก |

## Gate
ปลดล็อก backlog รายการใดรายการหนึ่งเมื่อ:
1. ผู้สร้างลอง v1.7 บนมือถือแล้วอย่างน้อย 1 รอบ และ/หรือ
2. มีผู้ใช้จริงหรือ deploy unlisted แล้วเก็บ feedback ขั้นต่ำ

## Non-goals ตอนนี้
ไม่ build B1–B8, ไม่ copy หนังสือทั้งเล่มลง UI, ไม่แนะนำผลิตภัณฑ์เฉพาะบุคคล
