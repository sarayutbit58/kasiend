# ADR 0029: PVD Projection Simulator (B3, education)

## Decision
ปลด backlog **B3** — เพิ่มเครื่องจำลอง **กองทุนสำรองเลี้ยงชีพ (PVD)** จากคลัง ก.ล.ต./SET  
แสดงเงินสะสมลูกจ้าง + เงินสมทบนายจ้าง + ผลตอบแทนสมมติ และเทียบกรณีไม่มีนายจ้างสมทบ

## Formula (educational)
จำลองรายเดือน:
- เงินเข้าเดือน = เงินเดือน × (อัตราสะสม% + อัตราสมทบ%) / 100
- `balance = balance × (1 + r) + เงินเข้า` โดย `r = ผลตอบแทนปี / 100 / 12`
- ทุก 12 เดือน: เงินเดือน × (1 + โตปี%)

## Non-goals
ไม่เชื่อมนายจ้างจริง, ไม่คำนวณภาษีละเอียดเมื่อลาออก, ไม่แนะนำแผนลงทุน Employee's Choice รายกอง
