# เขียนบทความจากประสบการณ์ตัวเอง ไม่รอ feedback ผู้ใช้

เปลี่ยนแผน ADR 0007: แทนที่จะรอ feedback จากผู้ใช้ก่อนเขียนบทความ → เขียนบทความจากประสบการณ์และความรู้ของผู้สร้างเองได้ทันที โดยไม่ต้องรอให้มีผู้ใช้จริง

เหตุผล: ผู้สร้างมีความรู้ด้านการเงินและการลงทุนจากการรวบรวมข้อมูลผ่านอินเทอร์เน็ต สามารถเขียนเนื้อหาที่มีคุณภาพได้โดยไม่ต้องพึ่ง feedback จากผู้ใช้ (Q8)

บทความตัวอย่าง: "ทำไมคนเงินเดือน 30,000 ควรมีเงินสำรอง 180,000 บาท" — อธิบายแนวคิดเงินสำรองฉุกเฉิน, ตัวคูณที่ควรใช้ตามประเภทงาน, ลิงก์ไป KalienD

หมายเหตุ: ไม่มีผลกับ Q2 (ยังไม่แชร์สาธารณะจนกว่าจะพอใจ)
