# ADR 0025: Three Bags (เงิน 3 ก้อน) on Stage 3

## Decision
ปลด backlog **B2** หลังมีผู้ใช้จริง 3 คนทดลองผ่าน — เพิ่มแผง “เงิน 3 ก้อน” ใน Stage 3 โดยใช้ผลจากสูตร retirement เดิม ไม่สร้าง calculator หน้าใหม่

## Mapping
1. **ก้อน 1 — เงินที่ต้องใช้:** เป้า ณ วันเกษียณ (`target`)
2. **ก้อน 2 — เงินที่มี/วางแผนแล้ว:** FV ของเงินออมปัจจุบัน + แผนออมรายเดือน (ถ้ามี)
3. **ก้อน 3 — ส่วนที่ต้องเติม:** `max(0, ก้อน1 − ก้อน2)` พร้อมข้อความออมเพิ่มต่อเดือนเมื่อยังขาด

## Non-goals
ไม่ดึงยอดจริงจาก SSO/กบข./PVD, ไม่แนะนำผลิตภัณฑ์, ไม่เปลี่ยนสูตรหลัก
