# Spec เครื่องคำนวณดอกเบี้ยทบต้น (ตัวที่ 2)

## Input
- เงินเริ่มต้น (P) — เงินก้อนที่มีอยู่แล้ว ณ วันนี้ (บาท)
- ออมต่อเดือน (PMT) — จำนวนที่ออมเพิ่มทุกเดือน (บาท)
- ระยะเวลา (t) — จำนวนปี
- อัตราผลตอบแทนต่อปี (r) — % ต่อปี (สมมติฐานการศึกษา ไม่ใช่การรับประกันผลตอบแทน)

## สูตร
- อัตราต่องวด (เดือน): r_monthly = (r / 100) / 12
- จำนวนงวด: n = t × 12
- มูลค่าในอนาคต: FV = P × (1+r)^n + PMT × [((1+r)^n − 1) / r]
- Total invested = P + (PMT × n)
-"ส่วนต่างผลตอบแทน" = FV − Total invested (visual: "ถ้าฝากไว้เฉยๆ ไม่มีดอกเบี้ยจะได้ X แต่ด้วยดอกเบี้ยทบต้นคุณจะได้ Y เพิ่มขึ้น Z")

## ข้อควรระวัง (ADR 0005)
- อัตราผลตอบแทนที่ผู้ใช้กรอกเป็นสมมติฐานเพื่อการศึกษา ไม่ใช่การรับประกัน
- ต้องมี disclaimer: "ผลตอบแทนจริงอาจแตกต่างจากสมมติฐาน ไม่ใช่คำแนะนำการลงทุน"
- คำนวณ client-side เท่านั้น (สอดคล้อง ADR 0006)
