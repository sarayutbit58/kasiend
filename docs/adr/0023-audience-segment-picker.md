# ADR 0023: Audience Segment Picker (no new calculators)

## Decision
เพิ่มตัวเลือกกลุ่มผู้ใช้บนหน้าเดียว: ทั่วไป / มนุษย์เงินเดือน / ฟรีแลนซ์ / ข้าราชการ / วัย 50+  
เมื่อเลือก จะปรับข้อความนำทาง ค่าตัวคูณเงินสำรอง ค่า preset และคำใบ้ใน 3 Stage เดิมเท่านั้น

## Non-goals
ไม่สร้าง calculator แยกต่อกลุ่ม ไม่เพิ่มหน้าสิทธิ/บล็อก encyclopedia จาก knowledge ทั้งเล่ม  
โปรไฟล์กลุ่ม = “ฟีเจอร์แยกไว้รอ” ในรูป config ที่ขยายได้ทีหลัง

## Rationale
Q33=ก + มีให้เลือก, Q34=จ แต่เตรียมกลุ่มไว้, Q35=ก จำกัดขอบเขตที่ 3 Stage
