# ADR 0030: Complete remaining backlog B4 B6 B7 B8

## Decision
ปลด backlog ที่เหลือทั้งหมดในรอบเดียว หลังผู้ใช้สั่ง “ทำทุกฟีเจอร์ใน Backlog”:
- **B4** จำลองโครงสร้างเงิน กบข. (การศึกษา)
- **B6** กฎถอนเงินประมาณ 4% หลังเกษียณ
- **B7** งบประมาณยืดหยุ่นฟรีแลนซ์ (50/30/20 + สำรอง 6–12 เดือน)
- **B8** ตรวจอัตราส่วนสุขภาพการเงินเบื้องต้น

## Source
คลัง `knowledge/` (กบข./SET/ก.ล.ต./คู่มือฟรีแลนซ์) — สูตรเป็นสมมติฐานการศึกษา ไม่เชื่อมระบบจริง

## Non-goals
ไม่ดึง My GPF, ไม่แนะนำแผนลงทุนรายตัว, ไม่เป็นคำปรึกษาเฉพาะบุคคล
