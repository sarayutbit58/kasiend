# ADR 0028: SSO Old-Age Benefit Estimate (B1, education)

## Decision
ปลด backlog **B1** — เพิ่มเครื่องประมาณการ **บำเหน็จ/บำนาญชราภาพประกันสังคม** แบบการศึกษา หลังบล็อกสิทธิสุขภาพ

## Educational formula (public-rule sketch)
- เกณฑ์เดือนสมทบสมมติ **180 เดือน** สำหรับแนวบำนาญ (ตรวจกับ สปส. ก่อนใช้จริง — เกณฑ์อาจต่างตามประเภท/ช่วงเวลา)
- ถ้าเดือนสมทบ **&lt; 180**: แสดงแนว **บำเหน็จ** แบบหยาบ = ค่าจ้างเฉลี่ย × 6% × เดือนสมทบ  
  (สมมติลูกจ้าง+นายจ้างฝั่งชราภาพราว 3%+3% ไม่รวมผลตอบแทนจริง)
- ถ้าเดือนสมทบ **≥ 180**: บำนาญรายเดือน ≈  
  `(20% + 1.5% × จำนวนปีเต็มที่เกิน 180 เดือน) × ค่าจ้างเฉลี่ย`  
  โดยจำนวนปีเกิน = `floor((months - 180) / 12)`
- เงื่อนไขอายุ/สิ้นสุดความเป็นผู้ประกันตน: แสดงเป็นข้อความ ไม่คำนวณสิทธิให้

## Non-goals
ไม่เชื่อม API สปส., ไม่รองรับ ม.40 แบบละเอียด, ไม่รับประกันยอดจริง, ไม่แนะนำผลิตภัณฑ์
