# KasienD · เกษียณดี

เครื่องมือวางแผนการเงินเพื่อ**การศึกษา** — หน้าเดียว self-contained  
3 ขั้นตอน: ตั้งกำแพงกันภัย → ให้เงินทำงาน → มองเป้าหมายไกล

## เปิดใช้

- ดับเบิลคลิก `index.html` หรือ
- GitHub Pages (ดูด้านล่าง)

## สิ่งที่มีในหน้า

- เครื่องคำนวณเงินสำรองฉุกเฉิน / ดอกเบี้ยทบต้น / เป้าเงินเกษียณ
- Stage Journey + เลือกกลุ่มผู้ใช้
- Dashboard สรุปแบบ live (คำนวณในเบราว์เซอร์เท่านั้น)
- ไม่มี login / ไม่เก็บข้อมูลเซิร์ฟเวอร์ / ไม่มี tracking

## ข้อจำกัดความรับผิดชอบ

เครื่องมือเพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำทางการเงิน การลงทุน หรือประกันสำหรับบุคคลใดบุคคลหนึ่ง

## Deploy — GitHub Pages

Repo นี้ตั้ง `index.html` ที่รากโปรเจกต์ → Pages จาก branch `main` path `/`

URL รูปแบบ: `https://<username>.github.io/<repo>/`

## โครงสร้าง

```
index.html          # แอพหลัก
CONTEXT.md          # คำศัพท์โปรเจกต์
docs/adr/           # บันทึกการตัดสินใจ
ROADMAP-90-DAYS.md  # แผน 90 วัน
blog/               # โครงบทความ
```

โฟลเดอร์ `knowledge/` เก็บฐานความรู้ภายใน (ไม่ขึ้น Pages)
