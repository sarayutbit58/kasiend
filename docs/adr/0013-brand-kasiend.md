# แบรนด์ KasienD / เกษียณดี

KasienD เป็นชื่อแบรนด์ใหญ่ (umbrella brand) ครอบคลุมทุกเครื่องมือในแอพ: การเงิน การลงทุน ประกัน สุขภาพ ชีวิต — "เกษียณดี" เป็นชื่อไทย/สโลแกน สื่อถึงเป้าหมายสูงสุดของการวางแผนการเงิน

ไม่เปลี่ยน Pilot Domain: เงินสำรองฉุกเฉินยังคงเป็นเครื่องมือแรก เพราะเป็นรากฐานของการวางแผนเกษียณ — "ก่อนจะเกษียณดี ต้องมีเงินสำรองฉุกเฉินก่อน"
