# Spec เครื่องคำนวณเป้าเงินเกษียณ (ตัวที่ 3)

## โหมด
Reverse FV + Gap Analysis — คำถามหลัก: "ต้องออมเดือนละเท่าไหร่ถึงจะมีเงินพอใช้หลังเกษียณ" (Q14=ก + Q17=ง)

## Input (Q15=ก — full, ทุกค่าปรับได้)

| ตัวแปร | หน่วย | บังคับ | Default |
|---|---|---|---|
| อายุปัจจุบัน | ปี | ✅ | — |
| อายุเกษียณ | ปี | ✅ | — |
| ค่าใช้จ่าย/เดือนหลังเกษียณ ณ มูลค่าเงินวันนี้ | บาท | ✅ | — |
| เงินออม/ลงทุนที่มีแล้วสำหรับเกษียณ | บาท | ไม่บังคับ | 0 |
| อายุคาดถึง | ปี | ✅ | 85 |
| ผลตอบแทนก่อนเกษียณ | %/ปี | ✅ | 5 |
| อัตราเงินเฟ้อ | %/ปี | ✅ | 2 |
| ผลตอบแทนระหว่างเกษียณ | %/ปี | ✅ | 3 |

## สูตร (ทบต้นรายเดือนตลอดทุกเฟส)

```
n_acc  = (ret_age − curr_age) × 12            # จำนวนงวดสะสม
n_ret  = (life_age − ret_age) × 12            # จำนวนงวดระหว่างเกษียณ
r_pre  = pre_return / 100 / 12                # อัตราต่องวด ก่อนเกษียณ
r_post = post_return / 100 / 12               # อัตราต่องวด ระหว่างเกษียณ
i_m    = inflation / 100 / 12                  # อัตราเงินเฟ้อต่องวด

# 1. ค่าใช้จ่าย ณ วันเกษียณ (ปรับด้วยเงินเฟ้อจากวันนี้)
E_ret  = expense × (1 + i_m)^n_acc

# 2. อัตราจริงระหว่างเกษียณ (real return)
real_m = (1 + r_post) / (1 + i_m) − 1
# ถ้า real_m ≈ 0 → fallback: target = E_ret × n_ret

# 3. เป้าเงินก้อน ณ วันเกษียณ (PV ของ annuity ที่จ่าย E_ret ทุกเดือน)
target = E_ret × (1 − (1 + real_m)^(−n_ret)) / real_m

# 4. มูลค่าจากเงินออมที่มีแล้ว
FV_saved = saved_now × (1 + r_pre)^n_acc

# 5. ส่วนที่ต้องหาเพิ่ม
shortfall = max(0, target − FV_saved)

# 6. ต้องออมเดือนละ (PMT ต้นงวด)
required_PMT = shortfall × r_pre / ((1 + r_pre)^n_acc − 1)
```

## Gap Analysis (Q17=ง ข้อ 3)
ถ้าผู้ใช้กรอกยอดออมจริง (planned_PMT):
```
FV_planned = FV_saved + planned_PMT × ((1 + r_pre)^n_acc − 1) / r_pre
gap = target − FV_planned
→ แสดง: "ยังขาด X บาท" หรือ "เกิน Y บาท" (gap ติดลบ = ขาด, บวก = เกิน)
```

## Edge Cases
- `ret_age ≤ curr_age` → แสดง error: "อายุเกษียณต้องมากกว่าอายุปัจจุบัน"
- `real_m ≈ 0` → target = E_ret × n_ret (กรณี inflaton ≈ post_return)
- `shortfall ≤ 0` → "คุณมีเงินพอเกษียณแล้ว ไม่ต้องออมเพิ่ม" + เป้า / FV_saved
- `required_PMT ≤ 0` → ไม่แสดง "อีก N เดือน" ให้แสดงข้อความยินดี
- ถ้า `life_age − ret_age ≤ 0` → แสดง error
- ทุก Rate = 0 → คิดแบบ linear (ไม่ทบต้น)

## Output (Q17=ง — 3 บรรทัด)
1. **เป้าเงินเกษียณ**: target แสดงเป็นเลขก้อนใหญ่ อันดับบนสุด
2. **ต้องออมเดือนละ**: required_PMT (บาท/เดือน)
3. **Gap**: ถ้ากรอก planned_PMT → แสดง gap
4. **ถ้าออมครบแล้ว**: แสดงข้อความยินดีแทน
